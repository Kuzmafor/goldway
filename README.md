# Goldway Telegram Bot 🛍

Telegram-магазин на [aiogram 3](https://docs.aiogram.dev/) для продажи внутриигровой валюты и предметов. Поддерживает русский/английский языки, простую капчу, каталог по играм, админ-панель с управлением товарами и заказами.

## Возможности

- 🌍 Двуязычный интерфейс (RU / EN)
- 🛡 Простая капча при первом входе
- 🛍 Каталог товаров с разбивкой по играм
- 📦 Оформление заказа через FSM (игровой ID + никнейм)
- 👤 Профиль пользователя с историей заказов
- ⚙️ Админ-панель: добавление/редактирование/удаление товаров, управление статусами заказов
- 💾 Хранение данных в SQLite (файл `goldway.db`)
- 🖼 Баннеры для разделов хранятся в `assets/`

## Структура проекта

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/<ваш-username>/bottg.git
cd bottg
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv .venv

# Windows (PowerShell)
.venv\Scripts\Activate.ps1
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Настроить переменные окружения

Скопируйте шаблон и заполните свои значения:

```bash
cp .env.example .env       # Linux / macOS
copy .env.example .env     # Windows (cmd)
```

Содержимое `.env`:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=123456789,987654321
ADMIN_USERNAME=xizcl
```

> `ADMIN_IDS` — список Telegram ID администраторов через запятую. Чтобы узнать свой ID, напишите боту [@userinfobot](https://t.me/userinfobot).

### 4. Запустить бота

```bash
python bot.py
```

При первом запуске файл `goldway.db` будет создан автоматически.

## Переменные окружения

| Переменная         | Описание                                              | Обязательная |
|--------------------|-------------------------------------------------------|--------------|
| `BOT_TOKEN`        | Токен бота от [@BotFather](https://t.me/BotFather)    | ✅            |
| `ADMIN_IDS`        | ID администраторов через запятую                      | ✅            |
| `ADMIN_USERNAME`   | Username администратора (без `@`) для кнопки поддержки | ✅            |

## Команды бота

| Команда  | Кто     | Описание                  |
|----------|---------|---------------------------|
| `/start` | Все     | Запуск бота + капча       |
| `/admin` | Админ   | Открыть админ-панель      |
| `/add`   | Админ   | Добавить новый товар      |

## Деплой

Бот работает в режиме long-polling, поэтому ему нужен хостинг, поддерживающий длительные процессы:

- **Render / Railway / Fly.io** — проще всего, есть бесплатные тарифы
- **VPS** (Ubuntu + systemd или Docker) — полный контроль

> ⚠️ Vercel и подобные serverless-платформы **не подходят** для polling-ботов.
